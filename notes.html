Time Dilation calculator

Did someone tell you "it will be done in 1 hour", and 3 hours later, it still is not done? Well, with this handy calculator, you can calculate how fast they had to be going, so that 1 hour for them would be 3 hours for you (a stationary observer).

Pick any units of time - seconds, hours, minutes, it doesn't matter - just make sure to use the same unit in both fields.

Click calculate to see results

If you want to calculate this for yourself, see time dilation (wikipedia). You can find "Time dilation equation" there and modify it to calculate v. That's what I did, using every piece of high school math memory that I had left.

Troubleshooting FTP

First step to fix any problem with FTP is to finally stop using FTP. Instead, you could use one of these alternatives:

  • SFTP (and if you are worried about security, because certificates are not signed, then I have something for you. For this to be effective, you need to have DNSSEC working.)
  • rsync (or rsync-ssl) with rsync daemon

Yes, I wrote this section only to say that FTP must die.
